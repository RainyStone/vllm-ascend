# 仿真路由档案：把专家负载均匀压到「前 4 张卡各自的首个专家」上。
#
# 口径 = slot 分布：每个数 = 该专家占本轮全部 route（T*top_k）的百分比，总和必须是 100。
# 稀疏写法：只列热点，剩下的 33.3332% 由其余 252 个专家均分（各 0.132274%）。
#
# 专家号怎么来的：E=256, R=8 → epn = E/R = 32，rank r 拥有连续区间 [32r, 32r+32)。
#   rank 0 -> 专家 [0,32)   首个 = 0
#   rank 1 -> 专家 [32,64)  首个 = 32
#   rank 2 -> 专家 [64,96)  首个 = 64
#   rank 3 -> 专家 [96,128) 首个 = 96
# 所以 0/32/64/96 正是前 4 张卡（card 0-3）各自的首个专家。
#
# 16.6667% 是能达到的**最大值**，不是随意的取值：单专家上限 = 100/top_k = 100/6 = 16.6667%。
# 真实 topk 里一个 token 的 6 个专家互异，所以任何专家最多被 T 个 token 选中，占 T*K 个 slot
# 的至多 1/6。想让 4 个专家各占 25% 是**数学上做不到的**（25% > 16.6667%）。
# 于是 4 个热点合计最多 66.6667%，这是本模型下「集中到 4 个专家」的物理上限。
#
# 预期 rank 级效果（home-rank rows 会打出来核对）：前 4 卡各约 1.66x 均值，后 4 卡各约 0.34x。
